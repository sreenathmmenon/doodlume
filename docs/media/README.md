# README media

`doodlume-spring-gameplay.gif` is a normal-speed, uninterrupted excerpt from a live Doodlume browser recording named `13-keyboard-spring-final-clean.webm`, source time 0.8 to 14.0 seconds. It shows a baseline jump, spring pickup and attachment, a higher jump, and completion. The export is 800 by 500 pixels at 12 frames per second, with a 128-color palette and a repeating loop. It contains no generated intermediate gameplay frames or screenshot montage.

The source rooftop picture is an AI-generated rough drawing. The spring was drawn and its ability authored through the studio. The recorded rooftop world was created through Meta Muse Spark Open on Fireworks AI, with local source-art processing. The example links in the main README open packaged playable worlds; they do not trigger a new generation request.

Photograph and illustration provenance for the example thumbnails is documented in [showcase credits](../../public/art/showcase/README.md).
