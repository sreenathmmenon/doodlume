# Model access

The live application uses Meta Muse Spark Open through Fireworks AI. Credentials remain on the server. Meta SAM 2.1 tiny and the separate LaMa background-repair model run locally in the application container.

Additional provider adapters are explicit alternatives, not claims of successful use. The recorded Baseten access attempt returned HTTP 403. Modal was verified as backup application hosting. Direct Meta API access has separate account and billing requirements.

For account restrictions, contact the provider through its official support channel. Include the error message, approximate request time and affected project. Never include API keys, full payment details or security codes in a support request.
